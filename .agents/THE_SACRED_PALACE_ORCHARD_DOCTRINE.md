## 2. The Four Pillars of Agba Engine's Multi-Century Scalability

### Pillar 1: Stylesheet Scalability (Per-Feature CSS over Monolithic Accumulation)
- **The Old World Flaw:** Dumping hundreds of unrelated utility classes, animations, and modal rules into a single gigantic `index.css` until no engineer dares touch a selector.
- **The Orchard Law:** `web/src/index.css` is permanently capped as the **Root Token Vault** (~490 LOC: CSS variables, font families, base glass resets, high-level layout scaffolding). Zero feature styles will ever be appended to it.
- **The Execution:** All future domain expansions—whether 3D museum artifacts, genealogical trees, or pan-African comparative views—are authored in focused, modular stylesheets (e.g. `web/src/hearth-viewport.css`, `web/src/bento-cells.css`). Vite automatically bundles them into an atomic, zero-latency production asset.

### Pillar 2: Coordinator Scalability (Pure Conductors Waving the Baton)
- **The Old World Flaw:** Screen-level tabs (`SearchTab.jsx`, `TranslateTab.jsx`) bloated to 1,200+ lines, holding network fetch logic, audio players, keyboard listeners, and canvas state.
- **The Orchard Law:** Coordinators are **pure conductors**. They wave the baton, managing layout geometry and coordinating sub-components, strictly capped at **300 LOC**.
- **The Execution:** Every new technical dimension—such as the **Àyànfẹ́ Ohùn Tonal Disambiguation Fork**, voice recognition, or genealogical tree navigation—is encapsulated within dedicated custom hooks (`useRootNetworkNodes.js`, `tonalDisambiguator.js`) or autonomous components (`<TonalDisambiguationFork />`). In the coordinator, integrating a new cosmic dimension takes exactly **one line of declarative JSX**, preserving vast headroom for generations to come.

### Pillar 3: Cellular Component Mitosis (Bento Plates)
- **The Old World Flaw:** Giant monolithic views that re-render everything when a single button changes state.
- **The Orchard Law:** Multi-cellular presentation decks (such as `EntityBentoDeck.jsx`) grow horizontally through **cellular mitosis**.
- **The Execution:** When `EntityBentoDeck.jsx` approaches its 450 LOC ceiling, it does not stop expanding. It performs mitosis: extracting autonomous cell plates (`<SovereignCrownCell />`, `<LivingAcousticHearthCell />`, `<VerifiedRegaliaCell />`, `<AncestryRibbonPlate />`). This instantly reduces the parent container from 355 LOC to 180 LOC on demand, opening fresh headroom for future sensory modalities (olfactory, kinetic, 3D photogrammetry).

### Pillar 4: Data-Blind Algorithmic & Corpus Scalability
- **The Old World Flaw:** Hardcoding entity names, special-case category conditionals, and tribal strings directly in JavaScript or Python application logic.
- **The Orchard Law:** Zero Yoruba words in engine code. All classification engines (`ontologyClassifier.js`, `tonalDisambiguator.js`, `relativesResolver.js`, `apply_category_sanitation.py`) operate purely on **graph topology, string normalization (NFC), and declarative JSON payloads**.
- **The Execution:** The algorithmic engine treats 1,397 nodes, 10,000 nodes, or 1,000,000 nodes identically. As we expand across West African civilizations (Edo, Igbo, Akan, Fon, Swahili), corpora shard cleanly into regional streams with Trie-based prefix indexes, guaranteeing sub-1.5s client boot times forever.
